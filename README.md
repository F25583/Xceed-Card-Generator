# Xceed Card Generator 🪪

أداة ذكية ومؤتمتة لإنشاء باقات التعريف وكروت الموظفين لشركة Xceed تلقائياً من خلال مطابقة البيانات والصور وتصديرها مباشرة إلى ملف PowerPoint مجهز للمراجعة والطباعة.

## 🚀 المميزات
- واجهة مستخدم رسومية (GUI) سهلة التعامل وبسيطة.
- مطابقة آلية بين الرقم التعريفي للموظف (ID) واسم ملف الصورة الخاص به.
- دمج الصور والبيانات بدقة متناهية فوق قالب الكارت الفارغ لتجنب الأخطاء البشرية.
- تصدير النتيجة النهائية بصيغة PPTX لسهولة التعديل أو الطباعة الفورية.

## 🛠️ المتطلبات وتشغيل البرنامج
1. تأكد من تثبيت لغة Python على جهازك.
2. قم بتثبيت المكتبات المطلوبة عبر الأمر التالي في الـ Terminal:
   ```bash
   pip install -r requirements.txt
   ```
3. قم بتشغيل الأداة:
   ```bash
   python app.py
   ```

## 📝 ملاحظات هامة لتجهيز الملفات
- **ملف الـ Excel:** يجب أن يحتوي على عمود باسم `ID` وعمود باسم `Name`.
- **صور الموظفين:** يجب أن يتم تسمية كل صورة بالـ ID الخاص بالموظف مباشرة (مثال: `37978.png`).
